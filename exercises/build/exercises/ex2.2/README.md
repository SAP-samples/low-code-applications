## Exercise 2.2: Enable the destination for Actions

1. Go to the lobby https://lcapteched.eu10.build.cloud.sap/lobby. Select *Control Tower* on the left and select the *Destinations* tile on the right

   ![RegisterDestination](../ex2/images/RegisterDestination.png)

2. Press *Add* to add a new destination

   ![RegisterDestinationAdd](../ex2/images/RegisterDestinationAdd.png)

3. Search for your new destination *ShoppingCart###*, select it in the list and press *Next*

   ![RegisterDestinationSelect](../ex2/images/RegisterDestinationSelect.png)

4. Select *All Environments* and press *Add Destination* 

   ![RegisterDestinationEnv](../ex2/images/RegisterDestinationEnv.png)

      # Summary
    You have now enabled the destination from the previous chapter to be used for Build Actions.
